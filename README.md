## 🌟 مميزات البوت
- 🎯 **تخصيص دقيق وموجّه للسعودية:** يرصد كافة الفرص الوطنية والدولية المعتمدة للمواطنين والمقيمين (أكاديمية طويق، سدايا SDAIA، مهارات المستقبل MCIT، مسك، تمهير/هدف، كاوست، ومنصات الخبرة الافتراضية الدولية مثل Forage/BCG/JPMorgan).
- 📜 **شهادات خبرة وتدريب معتمدة:** التركيز حصرياً على البرامج والمعسكرات وتجارب العمل التي تمنح شهادات خبرة رسمية أو شهادات تدريب على رأس العمل تؤهل لسوق العمل.
- 🆓 **مجاني 100%:** استبعاد تام لأي برامج مدفوعة أو تجارية.
- 🔗 **معلومات شاملة لكل فرصة:**
  - اسم البرنامج والجهة المنظمة.
  - المسار والتصنيف (ذكاء اصطناعي، علم وتحليل البيانات، علوم حاسب وبرمجة، أمن سيبراني وسحابي).
  - نوع الشهادة والمميزات (شهادة خبرة معتمدة، مكافأة تمهير، إلخ).
  - الشروط والمتطلبات الرسمية.
  - المدة وأسلوب التدريب (عن بُعد أونلاين / حضوري).
  - رابط التقديم والتسجيل المباشر.
- 🔄 **رصد آلي وتنبيهات فورية (Push Notifications):** فور اكتشاف أي فرصة أو معسكر جديد، يقوم البوت ببثها تلقائياً لكافة المشتركين والقنوات المرتبطة.
- 🔍 **بحث تفاعلي وتصفح سريع:** بحث بالكلمات المفتاحية (مثل: `سدايا`، `طويق`، `بايثون`، `عن بعد`) مع نظام صفحات تفاعلي وسلس.
- 📢 **دعم النشر التلقائي في القنوات والقروبات:** يمكن إضافة البوت كأدمن في أي قناة تيلجرام وسيتولى نشر الفرص فوراً.

## 🗂️ هيكل المشروع
```text
saudi-tech-certs-bot/
├── config.py                 # إعدادات التوكن، القنوات، وفترات الرصد
├── database.py               # قاعدة بيانات SQLite لإدارة المشتركين والفرص ومنع التكرار
├── scraper.py                # محرك الرصد الذكي وخوارزميات المعالجة اللغوية الطبيعية (NLP)
├── data_seed.py              # الكتالوج المعتمد الأولي لأفضل برامج وشهادات الخبرة المفتوحة
├── bot.py                    # معالجات البوت التفاعلية وواجهة الأزرار وقوائم التصفح
├── server.py                 # خادم هجين يجمع بين البوت وخادم ويب لفحوصات الصحة 24/7
├── cli_monitor.py            # مشغّل الرصد السيرفرلس (Serverless) المخصص لـ GitHub Actions
├── Dockerfile                # ملف بناء حاوية دوكر للتشغيل السحابي
├── docker-compose.yml        # تشغيل سهل وسريع بحاوية دوكر على سيرفرات VPS
├── render.yaml               # ملف الإطلاق التلقائي بضغطة زر على منصة Render
├── Procfile                  # إعدادات منصات PaaS (Railway / Heroku / Koyeb)
├── requirements.txt          # مكتبات بايثون المطلوبة
├── .env.example              # نموذج متغيرات البيئة
└── .github/
    └── workflows/
        └── monitor.yml       # جدول العمل المؤتمت على GitHub مجاناً 24/7
```

### 🥇 الطريقة الأولى: الاستضافة السحابية على Render.com (الأسهل والأشمل)
منصة Render تمنحك استضافة سحابية مجانية تدعم تشغيل خوادم الويب والبوتات، وقد قمنا بتزويد البوت بخادم صحة داخلي في `server.py` لضمان استمراره دون توقف:

1. أنشئ حساباً مجانياً على [Render.com](https://render.com) وسجّل الدخول عبر GitHub.
2. ارفع مجلد هذا المشروع إلى مستودع جديد على حسابك في GitHub (Public أو Private).
3. في لوحة تحكم Render: اضغط على زر **New +** ثم اختر **Web Service**.
4. اختر المستودع الخاص بك من القائمة.
5. عبّئ البيانات البسيطة التالية:
   - **Name:** `saudi-tech-certs-bot`
   - **Environment:** `Python 3`
   - **Region:** Frankfurt (أو الأقرب لك)
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python server.py`
   - **Instance Type:** `Free`
6. في قسم **Environment Variables** (متغيرات البيئة)، أضف:
   - `TELEGRAM_BOT_TOKEN` = `8693907736:AAG3TOa5omrUHAPqOUjTC6W_lK6aT1Ycp1c`
   - `TELEGRAM_CHANNEL_ID` = معرّف قناتك (اختياري، مثلاً `@MyTechCerts`)
7. اضغط **Deploy Web Service**.
🎉 مبروك! البوت الآن يعمل في السحابة على مدار 24 ساعة بدون انقطاع!

*(نصيحة إضافية: يمكنك وضع رابط الخدمة المجاني الناتج من Render في خدمة مجانية مثل [UptimeRobot.com](https://uptimerobot.com) ليرسل نبضة كل 5 دقائق لضمان بقائه مستيقظاً دائماً).*

### 🥈 الطريقة الثانية: السيرفرلس التلقائي عبر GitHub Actions (بدون أي سيرفر نهائياً!)
إذا كنت لا تريد تسجيل حساب على منصات استضافة، يمكنك الاستفادة من ميزة **GitHub Actions** المجانية، حيث تقوم خوادم جيت هب بفحص الفرص تلقائياً كل ساعتين وإرسالها فوراً إلى المشتركين وقناتك:

1. ارفع المشروع إلى مستودعك على GitHub.
2. ادخل على إعدادات المستودع **Settings** -> **Secrets and variables** -> **Actions**.
3. أضف سراً جديداً باسم `TELEGRAM_BOT_TOKEN` وضع فيه التوكن:
   `8693907736:AAG3TOa5omrUHAPqOUjTC6W_lK6aT1Ycp1c`
4. (اختياري) أضف `TELEGRAM_CHANNEL_ID` بمعرّف قناتك (مثال: `@YourChannel`).
5. ادخل على تبويب **Actions** في مستودعك، وفعّل خيار **Enable Workflows**.
🎉 سيعمل ملف `.github/workflows/monitor.yml` تلقائياً كل ساعتين 24/7 دون أي تكلفة أو سيرفر!

## 📢 كيفية ربط البوت بقناة تيلجرام للنشر التلقائي
1. أنشئ قناة جديدة في تيلجرام أو افتح قناتك الحالية.
2. اذهب إلى إعدادات القناة -> **Administrators (المشرفون)** -> **Add Admin (إضافة مشرف)**.
3. ابحث عن اسم مستخدم البوت: `@Shhadat7atmbot` وأضفه مشرفاً مع صلاحية نشر الرسائل (**Post Messages**).
4. ضع معرّف القناة في ملف الإعدادات أو كمتغير بيئة `TELEGRAM_CHANNEL_ID`:
   - مثال: `@MyChannelUsername`
5. بمجرد رصد أي فرصة جديدة، سيقوم البوت بنشر بطاقة الفرصة كاملة في القناة فوراً مع زر التسجيل المباشر!
